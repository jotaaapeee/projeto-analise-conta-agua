# projeto-analise-conta-agua
Analise de contas de agua para a matéria de Estatística Descritiva

Cria o ambiente virtual das libs "python3 -m venv venv"
Ativa o ambiente virtual "source venv/bin/activate"
Instala pelos requirements.txt "pip install -r requirements.txt" 

Pra executar o projeto "uvicorn app.main:app --reload"
